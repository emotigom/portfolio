01 · Product · Production education service

Gomdory

교사 주도 수업, 학생 보드, Courseware와 학생 프로젝트를 하나의 브라우저 기반 흐름으로 연결한 교육 웹 서비스입니다. 장기간의 수업 현장에서 반복해서 만난 운영 제약을 제품 요구사항으로 바꿨습니다.

Live ↗ GitHub ↗
Classroom Teacher-led workflow boards · Courseware · student projects
→
Web Next.js / TypeScript OpenNext · Cloudflare runtime
→
Data & Assets Supabase / R2 Auth · RLS · uploads · public assets

Problem

학교 수업에서는 설치, 계정 생성, 기기·네트워크 차이와 짧은 활동 전환 시간이 실제 사용성을 좌우합니다. 교사는 빠르게 수업을 열고, 학생은 복잡한 가입 없이 참여하며, 제출·공유 흐름은 수업 진행을 방해하지 않아야 했습니다.

Responsibility

현장 요구를 교사·학생 흐름, 화면, 세션, 권한, 데이터와 업로드 경계로 구조화하고 Next.js 애플리케이션과 Cloudflare 운영 환경까지 제품 단위로 연결하고 있습니다.

Technical decisions

Next.js App Router와 OpenNext Cloudflare 구성을 기반으로 교사 보드, classroom session, Courseware runtime과 학생 프로젝트 흐름을 분리했습니다. Supabase Auth/RLS와 R2를 사용해 사용자 데이터와 공개 자산의 경계를 나눴습니다.

Validation & result

실제 수업 환경에서 드러나는 브라우저·네트워크·운영 제약을 제품 계약과 QA에 반영하고, 배포·운영·복구 runbook을 코드와 함께 관리합니다. 기능 구현뿐 아니라 수업 중 실패했을 때의 경계까지 제품 범위로 다룹니다.

02 · Engineering flagship · Production web service

SK7 · 상균7데이즈

혈압 관찰값과 7일 생활습관 챌린지를 기록·조회·수정·회고하는 교육·연구 목적의 비진단형 웹 서비스입니다. 인증·데이터 소유권·배포·검증 경계를 깊게 다룬 엔지니어링 사례입니다.

Live ↗ GitHub ↗
Web React / TypeScript Cloudflare Worker
→
API FastAPI / Auth boundary Google Cloud Run
→
Data PostgreSQL / RLS Supabase Auth · PostgREST

Problem

생활 기록 서비스에서 인증 성공만으로는 충분하지 않았습니다. 로그인 이후에도 API와 DB가 사용자 소유권을 일관되게 지키고, 계정·데이터 삭제와 보존 기간까지 제품 동작으로 닫혀야 했습니다.

Responsibility

Backend / Full-stack 관점에서 REST API, 인증·데이터 경계, React 연동, Web/API 분리 배포와 QA·release 검증 흐름을 연결했습니다.

Technical decisions

Supabase Magic Link 세션의 access token을 FastAPI에서 확인하고, 같은 호출자 토큰을 PostgREST까지 전달해 PostgreSQL RLS가 소유권을 검사하도록 했습니다. CRUD·JSON export·계정 삭제와 30일 접근 만료를 제품 계약으로 구현했습니다.

Validation & result

Docker 이미지를 Cloud Build → Artifact Registry → Cloud Run으로 배포하고, GitHub Actions CI + 승인형 release pipeline, Playwright E2E, production smoke, rollback rehearsal과 release evidence로 실제 배포 상태를 검증했습니다.

Stack Python · FastAPI · PostgreSQL · React · TypeScript · Supabase Auth/RLS · Docker · GCP · Cloudflare · Playwright · pytest

Team evidence repository ↗
Result
최종 ExtraTrees + Pair-Neighbor 모델이 Public MAE 0.12669, Private MAE 0.1473을 기록했습니다. Public 계보는 V1 0.12828 → V7 0.12723 → 최종 0.12669로 원 점수를 함께 공개합니다.
My contribution
실험 기록·재현성 관리, 대안 모델 연구와 튜닝을 담당했습니다. 가설 수립·검증·최종 모델 선정은 팀 협업으로 진행했습니다.
Validation discipline

Relevant Background

교육 현장 경험을 제품과 엔지니어링의 출발점으로 연결합니다.

이전 경력을 숨기거나 교육과정 중심으로 설명하기보다, 실제 사용자를 오래 관찰한 경험이 어떻게 제품 요구사항과 기술적 경계로 이어졌는지 보여줍니다.

  1. 2020—Now

    초·중·고·특수학교 및 교육기관 AI·SW 교육 · 50개+ 현장

    학생·교사와 직접 수업을 운영하며 기기, 브라우저, 학교 네트워크, 계정과 개인정보, 짧은 수업 전환 시간 같은 비개발 환경의 제약을 반복적으로 경험했습니다.

  2. Product

    Gomdory · 현장 문제를 교육 웹 서비스로 전환

    교사 보드, classroom session, Courseware와 학생 프로젝트 흐름을 하나의 제품으로 연결하고, 수업 중 실제 사용을 기준으로 권한·데이터·업로드·배포·복구 경계를 설계하고 있습니다.

  3. 2026

    SK7 · Backend / Full-stack engineering

    FastAPI · PostgreSQL/Supabase · React/TypeScript · Cloudflare · Google Cloud 기반으로 인증, API, 사용자 데이터 소유권, 배포와 QA를 production 흐름까지 연결했습니다.

    KIST 시뮬레이션 연구 · DB 관리 · 웹 운영 경험

    계산 결과를 구조화하는 연구 경험, DB 관리, 홈페이지 개발·마케팅 운영 경험을 현재의 데이터·제품 관점으로 연결하고 있습니다.
