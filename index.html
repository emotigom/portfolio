01 · Flagship · Production web service

SK7 · 상균7데이즈

혈압 관찰값과 7일 생활습관 챌린지를 기록·조회·수정·회고하는 교육·연구 목적의 비진단형 웹 서비스입니다.

Problem

생활 기록 서비스에서 인증 성공만으로는 충분하지 않았습니다. 로그인 이후에도 API와 DB가 사용자 소유권을 일관되게 지키고, 계정·데이터 삭제와 보존 기간까지 제품 동작으로 닫혀야 했습니다.

Responsibility

Backend / Full-stack 관점에서 REST API, 인증·데이터 경계, React 연동, Web/API 분리 배포와 QA·release 검증 흐름을 연결했습니다.

Technical decisions

Supabase Magic Link 세션을 JWT 기반 API 접근과 연결하고 PostgreSQL RLS로 사용자별 행 소유권을 제한했습니다. CRUD, JSON export, 계정 삭제와 30일 데이터 수명주기를 명시적인 제품 계약으로 구현했습니다.

Validation & result

Docker 이미지를 Cloud Build → Artifact Registry → Cloud Run으로 배포하고, GitHub Actions CI + 승인형 release pipeline, Playwright E2E, production smoke, rollback rehearsal과 release evidence로 실제 배포 상태를 검증했습니다.

Stack Python · FastAPI · PostgreSQL · React · TypeScript · Supabase Auth/RLS · JWT · Docker · GCP · Cloudflare · Playwright · pytest

03 · ML experiment & validation

Stress Score Prediction

약 3,000행·16개 입력 특성의 tabular regression에서 모델 성능뿐 아니라 검증 계약과 실험 재현성을 함께 관리했습니다.

Private repository
Problem / Responsibility
제한된 데이터와 제출 횟수 안에서 leaderboard 과적합을 피하면서 개선 후보를 검증해야 했습니다.
Technical decisions
ExtraTrees를 기준으로 구조 피처와 Pair-Neighbor·거리 기반 조합을 실험하고 OOF, secondary validation, independent seed test를 분리했습니다.
Validation / Result
최종 Public MAE 0.1271229333을 기록해 baseline 0.1282776667 대비 Public MAE를 약 0.9% 낮췄습니다. Public score를 일반화 성능으로 과장하지 않고 미채택 가설과 제출 Notebook도 남겼습니다.

Stack Python · scikit-learn · pandas · NumPy · ExtraTrees · Pair-Neighbor · OOF validation

04 · 3D coding prototype

Gomdory Play

제한된 JavaScript 형태의 학생 입력을 안전하게 내부 명령으로 변환해 3D 물리 미션에 연결하는 코딩 교육 프로토타입입니다.

GitHub repository ↗
Problem / Responsibility
학생 코드를 그대로 실행하지 않으면서도 코드 수정이 3D 장면 변화로 이어지는 즉각적인 피드백이 필요했습니다.
Technical decisions
Acorn으로 제한된 JavaScript AST를 파싱하고 allowlist된 syntax만 내부 ThrowCommand로 변환했습니다. eval은 사용하지 않습니다.
Validation / Result
React Three Fiber + Rapier로 power·variable·addition expression·angle 미션과 keyboard/pointer aiming을 구현하고, WebGL fallback과 Vitest로 해석·상태 전이를 검증했습니다.
